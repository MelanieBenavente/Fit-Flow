# ARCHITECTURE
The codebase is structured into a multi-module system:

Layer-based separation: Clear distinction between Data, Domain, and UI logic.
Feature-based modularization: Each business functionality is encapsulated in its own module to improve build times and reusability.

# 🛠 Tech Stack & Libraries

Architecture Pattern: MVVM.

Dependency Injection: Dagger Hilt.

Networking: Retrofit & OkHttp for seamless API communication.

Local Storage: Room Persistence Library.

Repository Pattern: Decoupling the data source from the business logic to handle single sources of truth.

Monitoring: Firebase Crashlytics for real-time crash reporting and analysis.
